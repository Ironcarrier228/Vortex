Дальше по порядку:

## Этап 4 — Анализатор диска 🟡 (город готов, нужен MFT)

Сделано:

  предохранитель `max_nodes`, инкрементальные события статистики каждые 250 мс.
* ✅ `vortex-core/disk`: `TreeBuilder` со достройкой промежуточных каталогов и аккумуляцией размеров/файлов
  снизу вверх, категоризация расширений — 5 тестов.
* ✅ Сцена «город»: спиральная упаковка, высота ∝ размеру (нормировка ^0.42), цвет по категории/глубине/возрасту,
  анимация появления, тултип, хлебные крошки, список топ-40, drill-down, удаление в корзину с подтверждением
  и растворением объекта.
* ✅ Режим «sunburst» (кольцевые сектора по уровням, высота ∝ размеру) — переключается `M`.
* ✅ Кэш детей каталога на фронтенде + `disk_stats` для восстановления после перезапуска окна.

Дальше по порядку:

1. **MFT/USN-скан (мгновенный, с админом).**
   * `CreateFileW(L"\\\\.\\C:", GENERIC_READ, FILE_SHARE_READ|WRITE, ..., FILE_FLAG_BACKUP_SEMANTICS)`;
   * цикл `DeviceIoControl(FSCTL_ENUM_USN_DATA, MFT_ENUM_DATA_V0{ StartFileReferenceNumber, LowUsn, HighUsn }, ...)`
     → записи `USN_RECORD_V2/V3` (FRN, ParentFRN, FileName, FileAttributes);
   * дерево строить по FRN (map FRN → узел), размеры/даты — `FSCTL_GET_NTFS_FILE_RECORD` батчами;
   * при недоступности — автоматический откат на `jwalk` (уже есть) и тост «MFT недоступен: нет прав».
2. **Кэш между запусками.** Сериализовать дерево (`%LOCALAPPDATA%\Vortex\cache\scan-<id>.json`, сжатый gzip)
   + сохранённый USN-«baseline» для мгновенной проверки актуальности (`FSCTL_READ_USN_JOURNAL`).
3. **Дополнительные режимы**: treemap-плоскость, «топ-100 крупнейших файлов», поиск дубликатов
   (размер → частичный хэш → полный хэш). Это же — естественное продолжение drill-down.
4. **UI-полировка**: легенда категорий, фильтр по типам, мультивыделение, `rfd`-диалог выбора каталога
   вместо `window.prompt`, undo-подсказка после удаления.
5. **Производительность**: порционный рендер появления объектов (не более N зданий за кадр),
   LOD для городов >5000 объектов, инстансинг вместо меша на каждый объект (сейчас: меш на объект, до 900 объектов).
